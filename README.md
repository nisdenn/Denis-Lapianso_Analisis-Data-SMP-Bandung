# Analisis Data SMP Bandung

Proyek analisis data menggunakan Pandas dan Matplotlib untuk memproses dan memvisualisasikan dataset tentang SMP Negeri di Bandung.

## Fitur Utama

- Membaca dataset CSV.
- Membersihkan dan memanipulasi data dengan Pandas.
- Menyajikan visualisasi data (grafik bar, pie chart, dsb.) menggunakan Matplotlib.

## Cara Penggunaan

1. Install requirement:
   ```bash
   pip install -r requirements.txt
   ```
2. Jalankan script:
   ```bash
   python src/main.py
   ```

## Struktur Direktori

- `src/` : Berisi source code (`main.py`).
- `data/` : Berisi dataset (`data_smp_negeri_bandung.csv`).
